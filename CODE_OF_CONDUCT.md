# Code de conduite

Nous voulons un espace accueillant et respectueux. Les participants s'engagent à :

- rester courtois, y compris en désaccord ;
- accepter les critiques constructives sur le code, pas sur les personnes ;
- ne tolérer ni harcèlement, ni insulte, ni discrimination ;
- ne pas publier d'informations privées d'autrui.

Les messages ou contributions qui y contreviennent peuvent être modérés ou
supprimés, et leurs auteurs exclus du projet. Pour signaler un comportement,
contacte les mainteneurs via le signalement privé GitHub (onglet *Security*).

Adapté du [Contributor Covenant](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).
